1. Hearing you

Jarvis listens to plain chat — no prefix needed for most things:

You typeWhat happens
@Jarvis how do I join a companyFull answer (1 daily credit).
hey jarvis why is collect brokenSame as a ping — its name is the address.
jarvis / come jarvisFree nudge: it asks what you need.
collect is broken pls (no name)Bug triage in support channels or with a plea word — fix if known, logged to the ticket inbox.
-jarvis <question>Explicit command, full power: live state, lore, web search, images, documents.
/jarvisSlash twin, works in any server.

2. Building context

Every answer is assembled from live evidence, in this order:

Server scope — this server's currency, settings, live local race. Other servers are invisible and it says so.
Economy snapshot — exact GDP, GSI, inflation, gold backing.
Roles — your Discord roles plus anyone you @mention, resolved live. Ranks come from here, never guessed.
Server lore — past channel history for who/what/when questions.
Source code — for code and bug questions it searches every bot source file (phrases first, then definitions, then mentions) and quotes file:line.
Dossiers — Primary-written facts about people, highest authority when present.

3. Answering

A provider from the model chain writes the reply in plain Discord text. Bad output (safety templates, parroting, stutter) is detected and the next model tries instead — trash never reaches chat. Long answers are chunked so limits cut between messages, never mid-thought.

4. Autonomy

StateMeaning
Quiet (default)Auto-talk is staff-only. Everyone else uses -jarvis.
Awake (~20 min)Owner's call wakes the server — Jarvis answers everyone in all channels, then stands down alone.
Asleep (shhh)No unsolicited replies anywhere. Only the owner's own call breaks through (and re-wakes).
Left channelleave the market exits one channel until come back.
Community-setup jarvis community on restores everyone-talks mode per server.

5. Bug desk loop

member:  -bug collect gave nothing, expected grain
jarvis:  Ticket #12 filed — investigating…
jarvis:  cause + bot.js:line + exact fix (proposes only)
owner:   -bug approve #12   → authorized, agent applies it
owner:   -bug close #12     → done, logged in ticket history

The bot proposes fixes and stops for authorization. It cannot edit files and never claims otherwise.
